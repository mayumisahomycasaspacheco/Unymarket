# Unymarket
Unymarket is the frontend shell of a buy-and-sell website for estudents, with a hand-draw retro desktop look. Everything is made with plain HTML, CSS and little JavaScript.

![Unymarket](https://cdn.hackclub.com/01a11d76-a390-7a66-931c-02100a8b3da3/image.png)

## What does it do?
Unymarket is a plantilla of website where people could buy and sell second things like books, clothes and electronics. This repository is the visible part of that idea: a login page, a register page and a forgot your password? page, plus a desktop made of icons and windows (Buy, Sell and Profile) that is still in progress. All the art was drawn by hand in Paint with a crayon brush and then given a matching crayon texture.

I made it so other hackers can use it as a starting point. You can take it to build your own buy-and-sell site, or just follow its look and feel for a different project.

## How to try it?
1. Open the live demo: https://mayumisahomycasaspacheco.github.io/Unymarket/
2. Type any example email and password.
3. Press Enter to go to the desktop.

You can also go to the Releases section of this repository to download the project as a .zip.
